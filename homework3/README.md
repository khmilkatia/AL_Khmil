# Аналізатор тексту

Програма читає український текст із файлу, рахує слова та унікальні слова,
будує словник частотності, а з прапорцем `--lemmas` рахує частотність лем (pymorphy3).

## Файли

- `text_analyzer.py` — програма
- `test_text_analyzer.py` — автоматизовані тести (unittest)
- `sample_text.txt` — зразок тексту (300 слів)
- `requirements.txt` — залежності
- `README.md` — цей файл

## Створення віртуального середовища

macOS / Linux:

```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Windows:

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Після активації на початку рядка терміналу з'являється `(venv)`.

## Запуск програми

```
python text_analyzer.py sample_text.txt --top 10
python text_analyzer.py sample_text.txt --top 10 --lemmas
```

## Запуск тестів

```
python -m unittest -v
```

## Обробка помилок

Програма повідомляє зрозумілим текстом, якщо: файл не знайдено, немає доступу,
вказано папку замість файлу, кодування не UTF-8, текст порожній
(власний виняток `EmptyTextError`).

## Порівняння NLTK і pymorphy3

| Параметр | NLTK | pymorphy3 |
|---|---|---|
| Призначення | Універсальний набір інструментів для обробки природної мови | Морфологічний аналізатор |
| Можливості | Токенізація, стемінг, лематизація (WordNet), POS-теґінг, корпуси, парсинг | Лематизація, визначення частини мови та граматичних ознак, відмінювання слів |
| Застосування в аналізі тексту | Підготовка тексту, підрахунок частотності, робота з корпусами | Зведення словоформ до лем перед підрахунком частотності |
| Українська мова | Обмежена: немає готового українського лематизатора | Так, через пакет `pymorphy3-dicts-uk` |
| Англійська мова | Так, найкраща підтримка | Ні |
| Простота | Багато модулів, треба окремо завантажувати дані (`nltk.download`) | Простий API: `morph.parse(слово)` |
| Переваги | Широкий функціонал, багато корпусів і документації | Швидкий, добре працює з багатою флексією слов'янських мов |
| Обмеження | Для української потрібні сторонні моделі | Не бачить контексту: при омонімії бере найімовірніший розбір |
| Встановлення | `pip install nltk` + завантаження даних | `pip install pymorphy3 pymorphy3-dicts-uk` |

Приклад коду NLTK:

```python
from nltk.tokenize import wordpunct_tokenize
print(wordpunct_tokenize("Мама мила раму."))
```

Приклад коду pymorphy3:

```python
import pymorphy3
morph = pymorphy3.MorphAnalyzer(lang="uk")
print(morph.parse("книгою")[0].normal_form)
```

**Примітка про обмеження.** pymorphy3 аналізує кожне слово окремо, без контексту.
Тому для слова «тому» (у значенні «через це») він може дати лему «том» —
це найімовірніший розбір, але в реченні він хибний (омонімія).
